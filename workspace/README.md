# Workspace — 你的 AI 从这里"醒来"

> 这个目录下的文件定义了你的 AI 助手。每次对话开始，AI 都会读取这些文件来重建自己。

## 文件总览

| 文件 | 作用 | 首次必改？ |
|------|------|-----------|
| **SOUL.md** | AI 的人格、行为准则、调性 | ✅ |
| **USER.md** | 你是谁、你的目标和偏好 | ✅ |
| **IDENTITY.md** | AI 的名字、角色、已知缺陷 | 可选 |
| **AGENTS.md** | AI 的工作方法论 | 可选 |
| **MEMORY.md** | 记忆索引（跨对话持久化） | 自动维护 |
| **TOOLS.md** | 工具能力和安全红线 | 可选 |
| **HEARTBEAT.md** | 定时心跳行为 | 可选 |
| **BOOTSTRAP.md** | 新 session 启动任务 | 可选 |

## 快速开始

1. 编辑 `SOUL.md` — 定义 AI 的风格（直接？幽默？严谨？）
2. 编辑 `USER.md` — 告诉 AI 你是谁，你最关心什么
3. 开始对话，AI 会按你的设定回复

## 注意事项

- 这些文件**升级时永远不会被覆盖**——它们属于你
- 改了文件后，**下一次新对话**生效（当前对话不会重新加载）
- 建议每个文件 50-200 行，太长会占用 AI 上下文空间
