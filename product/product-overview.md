# ClawKing — Product Overview

## Product Name
ClawKing

## One-Liner
下载即用的 AI 数字员工——OpenClaw Agent 引擎 + 国际顶级模型 + 1000+ Skills，面向中国小微企业主和超级个体的 7×24 自主 Agent 客户端。

## Problem
中国用户无法直连国际顶级 AI 模型（Claude/GPT/Gemini），而国内竞品用弱模型跑 Agent 不可靠（"数字智障"）。同时，原生 OpenClaw 配置门槛极高——需要手动装 Skills、配 Cron、设网络代理，非技术用户无法使用。

## Solution
ClawKing 将 OpenClaw 全套能力封装为开箱即用的客户端产品：
- **算力中转通道**：内建国际模型路由，让 Agent 真正能干活
- **Server 模板**："选岗位即用"——预装 Skills + Cron + Channel 组合，老板不需要懂技术
- **桌面 + 移动双端**：Electron + React Native，7×24 自主运行
- **白手套服务**：高客单价 + 专人配置，不是卖工具是替代雇人

## Target Users
- 跨境电商卖家（多平台运营、客服、竞品监控）
- 自媒体人/MCN（小红书/公众号/微博多平台运营）
- 一人公司/小工作室（邮件、日程、财务全靠自己）
- 小微企业主（3-10 人团队，老板什么都兼）

## Core Value Propositions
1. **能做事，不只是聊天** — 40-50 预装 Skills + ClawHub 市场 1000+
2. **自己跑，不用盯** — Cron 引擎 7×24 定时执行（邮件摘要、竞品监控、周报生成）
3. **越用越聪明** — LCM 长期记忆系统，记住偏好和历史上下文

## Business Model
高客单价订阅制：¥500-1,000/月（年付 ¥5,000-10,000）。对标雇人成本的 1/5~1/3。
